# Start a project

This repository is an existing plugin brought up to the omarchy-plugin-template
standards, so `scripts/init.mjs` is not used here (`.template/project.json`
records the identity with `"initialized": true`).

For brand-new plugins, start from the template itself:
https://github.com/tcballard/omarchy-plugin-template — see its
[SETUP guide](https://github.com/tcballard/omarchy-plugin-template/blob/main/docs/SETUP.md).
